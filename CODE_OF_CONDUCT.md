# Code of Conduct

This is a small project. The rules are short.

## Expected

Be direct about code and civil about people. Assume the other person read the
docs and still got stuck, because that usually means the docs are wrong.
Disagree with the argument rather than the author.

## Not accepted

Harassment, personal attacks, demeaning comments, sustained disruption of
issues or pull requests, and publishing anyone's private information.

## Scope

Issues, pull requests, discussions, commit messages, and anywhere someone is
representing the project.

## Enforcement

Comments that break this get edited or deleted, and repeat offenders get
blocked from the repository. There is no appeals process.

Report a problem through [GitHub's report abuse form](https://github.com/contact/report-abuse),
or by opening an issue if it is something that can be discussed in public.
